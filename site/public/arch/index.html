mailbox 1B2D1B1
mailbox 2E1
worker 0A1 → A2 → A3 · 一次一条

无 key: round-robin · 只有 1 个 mailbox (Sequential) 时全局 FIFO

关于 Ech0

是什么

Ech0 是一个自托管的轻量个人微博（时间线）平台。 一个 Go 二进制同时提供 REST API 与内嵌的 Vue 3 SPA，数据默认全部落在 data/：SQLite 数据库、上传文件与日志。

后端按 handler → service → repository → model 严格分层，由 Wire 在编译期装配；副作用经进程内事件总线解耦； LLM 能力分为出站的 Agent 与入站的 MCP 两个方向。pkg/ 下是几个与业务无关的自研库。

设计基调：轻量优先；依赖一律指向纯词汇包。
